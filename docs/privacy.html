プライバシーポリシー

最終更新日: 2026年8月24日

「YouTubeポッドキャスト公開チェック」（以下「本ツール」）は、開発者本人が個人利用のために 運営する自動化スクリプトです。本ツールは開発者自身のYouTubeチャンネルの動画情報にのみ アクセスし、第三者のデータを取得・収集することはありません。

取得する情報

本ツールは、YouTube Data API を通じて、開発者自身のチャンネルが所有する動画の タイトルおよび公開設定（公開・限定公開・非公開）のステータスのみを取得します。

情報の利用目的

取得した情報は、動画が意図せず「非公開」に変更された場合にそれを検知し、 「公開」設定へ復帰させる処理、および開発者本人への通知メール送信のためにのみ使用します。

第三者への提供

本ツールが取得した情報を、開発者本人以外の第三者へ提供・販売・共有することはありません。

データの保存

本ツールは取得した情報を恒久的に保存するデータベースを持ちません。 実行のたびにYouTube側の最新情報を取得し、処理後は保持しません。

お問い合わせ

本ツールに関するお問い合わせは、開発者本人までご連絡ください。
